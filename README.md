One line, at most 100 characters, that sums up the entrant's week — 61 bounties entered, 18 placed, $0.00 claimed — for make.fun's "Your Week in One Line" bounty.

> 61 entries, 18 placements, $0.00 claimed — my week was a leaderboard with no payout window.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
